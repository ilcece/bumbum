从仓库根目录读取 [后台设计与交互规范](../../../docs/ADMIN_UI_GUIDELINES.md)。按场景查阅 [桌面验收手册](../../../docs/ADMIN_DESKTOP.md) 和现行产品规则。

- 写代码前列出本次影响的入口与同类调用点，明确动作属于字段、记录、分区还是整份表单。用规范指向的现有组件作为样板，在同一批修改中核对各个调用点。
- 界面可点击范围、提示、键盘入口和视觉表达要一致。例如可穿透指标整卡操作，静态指标无点击暗示；单字段敏感查看动作贴着字段值，保留既有授权与审计。
- 全量走查按模块清点功能，按交互类型并排比较。使用合成数据，在 1920×1080 截取稳定状态，核对实际办理去向。记录源码核对、入口实测、完整业务复验、视觉复核各自的范围和缺口。
- 状态改变、权限调整及部署授权沿用 AGENTS.md。失败、空态、校验、处理中、完成和返回分别验证，历史截图只用于可追溯的对照。
