## 1. 项目定位

将 ZP 婚礼伴手礼机会规划为一个**付费产品交付 + 数字体验验证 + 五台山文创渠道探索**的综合试点。

这次项目不是单纯发放 2,000–3,000 份礼物，也不是把祈愿系统扩展成 BUMBUM 的长期愿景。它的价值在于：在可控成本和明确交付边界下，把数字佛牌、手串放到真实使用场景中，验证实体信物与持续数字体验是否成立，并了解后续文创渠道是否存在真实合作需求。

## 2. 已知机会与待确认事项

### 2.1 已知信息

- ZP 也有五台山文创饰品销售渠道，包括部分景区文创实体店及五台山线上购物平台。具体合作门店、平台名称、准入要求和合作条件尚待确认。

- 淘宝、抖音、京东店铺的具体上架时间、平台规则、商品类目及宣传文案要求。
- 批量 NFC 芯片配置、密钥管理、单枚芯片与实物映射、包装和物流的真实产能与成本。
- 活动后是否进行自愿用户回访，以及回访入口、数据范围和授权方式。

## 3. 四个目标

1. **完成付费交付：** 在报价覆盖全部合理成本的前提下，按双方确认的规格、数量和日期交付产品，避免把未计入的开发、人工、质检、包装或物流成本当作免费投入。
2. **验证数字体验：** 确认普通收礼者能够独立完成 NFC 触碰、进入祈愿 H5、获得当天主福卡，并在之后有机会再次触碰。
3. **验证生产与履约：** 跑通从产品打样、芯片配置、单品映射、质检、包装到批量交付的流程，为未来文创产品小批量销售积累经验。
4. **探索后续渠道：** 借由 ZP 的行业关系与销售渠道，了解五台山文创门店和线上平台的真实需求；再评估 BUMBUM 自有淘宝、抖音、京东店铺是否适合承接后续销售。渠道机会必须经过对话、准入和小批量试销验证，不能把人脉或店铺注册等同于订单。

## 5. 商务与成本原则

### 5.1 报价底线

“至少覆盖成本”必须按**项目总成本**核算，而不是只看饰品采购价。报价测算至少应包含：

- 佛牌、手串及配件采购成本；
- NFC 芯片、芯片配置/写入、密钥管理及单品映射成本；
- 样品、工艺验证、返工和质检成本；
- 包装、说明卡、定制设计与印刷成本；
- 生产协调、人工、打包、运输、仓储和交付成本；
- 为本项目专门产生的 H5 配置、内容定制和运营工作量；
- 平台、支付、税费等适用费用；
- 备用品、损耗和不可预见成本预留。

建议先计算总成本与单位成本，再确定对外报价；在双方尚未确认范围前，不承诺免费增加定制功能或无限次改稿。

### 5.2 建议协商的商务条款（尚待双方确认）

- 书面确认产品规格、数量区间、单价、交付时间、验收标准和变更流程。
- 可讨论采用“预付款后启动定制与采购、发货前支付尾款”的方式；具体比例和节点由双方协商，不视为已达成约定。
- 若数量、包装、材质或定制内容发生变化，应重新核算成本和交期。
- 生产前由 ZP 对样品、包装文案及定制内容确认留档。
- 约定产品缺陷、运输损坏、数量差异和补发的责任边界。

## 6. 产品与生产策略

### 6.1 V1 产品边界

婚礼试点优先复用祈愿 H5 V1 的“一碰一签”核心闭环，不因 2,000–3,000 份的规模而提前加入稀有度/SSR、个人收藏中心、复杂养成、登录账户、所有权绑定、转赠转售或实体换新。

婚礼专属祝福可以作为轻量内容配置，但不得因此改写核心业务规则或让婚礼项目阻塞 MVP。分享功能若尚未经过单独评审，不列为婚礼交付的默认前提。

### 6.2 批量 NFC 交付门槛

在承诺大批量交付前，必须先验证批量流程，不得默认现有单卡流程已具备量产能力：

1. 选定最终芯片、嵌入位置和产品工艺，完成真实样品测试。
2. 为每件实物建立唯一内部记录，确保实体产品、芯片标识、数字物品记录和包装批次一一对应。
3. 明确芯片密钥生成、配置、访问、备份和操作审计方式；密钥不能放入公开表格、二维码或客户端代码。
4. 生产时保留批次号、配置结果、质检结果和不合格品处理记录。
5. 每件产品都应完成规定的登记/映射核验；按风险抽样使用不同手机系统进行真实触碰测试，并保留备用品和替换流程。
6. 包装提供清晰的 NFC 触碰指引及二维码备用入口。二维码可访问的功能与安全边界必须明确，不能把静态二维码宣传为等同于动态芯片认证。
7. 建议初步评估约 3%–5% 的备用品比例，但最终比例应根据供应商质量、单价、交期和预算确定。

如果现有后台没有安全、可复核的批量配置能力，必须先设计并验证受控流程，再决定是否量产；不能临时用未经审查的脚本处理生产密钥。

## 7. 三条渠道路线

### A. 婚礼伴手礼：验证真实体验

- 以礼物体验为主，避免强制注册、强制留手机号或现场销售推销。
- 包装和页面用简洁文字解释如何触碰、如何获得祝福，以及二维码备用入口。
- 只收集完成产品验证所需的最少数据；宾客个人信息、联系方式或可识别的触碰记录不得默认交给新人或第三方。
- 婚礼照片、新人姓名、婚礼专属文案及任何公开宣传，需先取得相应授权。

### B. 五台山文创渠道：验证合作需求

- 婚礼前准备一页产品介绍、实物样品、价格结构和体验演示，但婚礼当天不把宾客当作销售线索名单。
- 通过 ZP 介绍后，另约相关门店或平台负责人沟通，了解客群、供货价、零售价、结算、售后、上架要求和试销数量。
- 优先争取小批量、可复盘的试销，不因一次介绍就投入大规模库存。
- 对“祈愿”相关文案保持克制，不承诺灵验、健康、财富或其他现实结果。

### C. BUMBUM 自有电商店铺：验证直接销售

- 分别核对淘宝、抖音、京东的店铺状态、类目准入、商品发布和宣传要求。
- 准备统一的产品规格、真实材质说明、芯片体验说明、售后政策、产品图片和价格。
- 先选择一个适合的渠道小批量试销，再根据转化、咨询、退货和履约数据决定是否扩展。
- 自有店铺与五台山合作渠道的价格、库存、包装和品牌授权规则需提前协调，避免冲突。

## 8. 数据与复盘

### 8.1 必须区分的口径

- **发放数量：** 实际交付的伴手礼数量。
- **触碰信物数：** 至少成功进入体验的不同芯片/物品数量。
- **祈愿完成数：** 服务端确认成功生成当天主福卡的信物数。
- **再次触碰数：** 在后续日期再次触碰的信物数。
- **独立人数：** V1 不要求用户账户，因此通常不能从芯片数准确推导独立人数；不得把不同芯片数或触碰次数宣传为独立用户人数。

### 8.2 建议观察的指标

- 首次触碰成功率与祈愿完成率；
- 页面加载、芯片读取、二维码备用入口和兼容性问题；
- 7 天、30 天再次触碰情况；
- 自愿反馈中最喜欢/最困惑的体验；
- 每份产品的全成本、次品/替换比例与交付及时率；
- 五台山门店/平台的有效沟通数、试销意向、实际准入和订单；
- 自有电商店铺的商品审核、咨询、转化、退货和售后情况。

先建立可靠基线，再决定具体目标值。不得为追求数据而强制用户登录或收集不必要的个人信息。

## 9. 主要风险与应对

| 风险 | 应对 |
|---|---|
| MVP 延期，影响婚礼准备 | 11 月只完成核心闭环；12 月集中修复；婚礼定制不进入 MVP 必需范围 |
| 把 2,000–3,000 份当作已确认订单 | 婚期、数量、规格、报价与付款条件书面确认后再采购和量产 |
| 只计算材料成本，项目实际亏损 | 计入芯片配置、人工、包装、质检、物流、定制和备用成本 |
| 单卡流程无法支撑批量生产 | 先做小批量产线验证，确认安全配置、单品映射、审计和替换流程 |
| 婚礼后没有复访或渠道订单 | 分别衡量体验行为与渠道转化，不把曝光等同于留存或商业成功 |
| 宾客隐私或婚礼内容授权不清 | 最小化数据收集；公开使用姓名、照片、反馈或联系信息前取得授权 |
| 祈愿宣传引发误解 | 祝福是情感体验，不宣称保证现实结果，不用稀有度暗示更灵验 |
| 自有店铺或合作平台不满足准入 | 提前核对平台规则、类目、商品信息和售后要求，先小批量验证 |

## 10. 角色与决策

- **BUMBUM 创始人：** 产品范围、成本底线、品牌表达、供应商选择和最终验收负责人。
- **ZP：** 付费项目对接方、婚礼规格确认方，并可能提供行业渠道引荐；渠道介绍不代表第三方已承诺合作。
- **供应商/加工方：** 材料、工艺、产能、质量、交期与报价，需另行选定并核验。
- **开发协作：** 按已确认的 V1 PRD 实现与测试；任何新增婚礼专属功能先评估是否影响 MVP 和批量交付。

## 11. 里程碑验收清单

### MVP（2026 年 11 月底目标）

- [ ] 真实 NFC 触碰可进入祈愿体验，二维码备用入口行为明确。
- [ ] 每件信物每天最多生成一张主福卡；重复请求幂等。
- [ ] 福卡与愿力可靠保存，提供信物记录查看，异常时有明确提示；V1不含回向。
- [ ] 真实手机和网络异常场景完成测试。
- [ ] V1 不依赖个人账户、SSR、复杂养成或藏品流转。

### 12 月试用与优化

- [ ] 试用用户、反馈方式和隐私说明明确。
- [ ] 建立首次触碰、祈愿完成、再次触碰等统计口径。
- [ ] 完成高影响问题修复并形成版本记录。
- [ ] 形成婚礼试点的产品候选版本和已知限制清单。

### 婚礼量产前

- [ ] 婚期、数量、产品配比、预算、付款、交付与验收条件书面确认。
- [ ] 样品、材质、工艺、包装和文案获确认。
- [ ] 全成本测算满足报价底线。
- [ ] 批量芯片配置、密钥管理、单品映射、质检与替换流程通过小批量验证。

### 婚礼后 30 天内

- [ ] 汇总交付质量、触碰/祈愿/再次触碰数据及成本。

- [ ] 整理五台山渠道的实际沟通进展、试销条件和下一步负责人。

## 12. 下一步必须确认的事项

1. 婚礼准确日期及伴手礼最终数量区间。
2. 佛牌、手串的款式、数量配比、材料与包装偏好。
3. ZP 对应的预算范围、报价方式、付款节点及验收条件。
4. 婚礼专属祝福内容、品牌露出和对外使用权限。
5. 生产供应商、交期、批量芯片配置方案和质检责任人。
