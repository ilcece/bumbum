# 物品管理：创建、详情、编辑与图片验收

当前正式Umi后台以[新版四组验收](ADMIN_DESKTOP.md#8-新版数字档案后台四组验收)及[测试数据验收](ADMIN_DESKTOP.md#9-验收数据包与整批清理)为准。本页草稿/旧单件文字接口供兼容核对，旧单件图片上传、读取和外链保留已退役；图片统一在共用款式维护。

目的：按真实编号维护物品，核对关联、普通保存和图片全过程。使用交付分支及本手册，不把代码提交当作cece验收或main/服务器已更新；当前任务见[TODO](../TODO.md)，历史证据见[CHANGELOG](../CHANGELOG.md)。本次Make展示组合已用于布局、列表和详情/编辑，旧交互原型仅供参考；页面控件与交互采用Ant Design 6，业务权限仍按现行规范。

## 1. 准备与边界

先停止旧前后端，保留配置/账号/数据，在GitHub Desktop获取远端并选择交付分支；核对提交说明后按[本地运行](LOCAL_DEVELOPMENT.md)安装锁定依赖并启动。含图片的新后端须先按[第14节](LOCAL_DEVELOPMENT.md#14-物品与私有图片后端升级)检查005，已有库先完整备份再升级，不重建或删除卷。香港旧环境不执行；杭州和生产操作另行授权。

本机图片验收还须有本人私有目录、足够磁盘及获准开发目标的MEDIA_ENABLED=true；生产保持false，隔离恢复不替代真实异盘备份。配置命令及Windows权限限制只看本地手册，不在本页重复。页面不要求秘密、真实卡或数据删除，测试编号已存在则换未用编号。

## 2. 连续创建与列表

| 操作 | 应看到什么 |
|---|---|
| 在列表先提交项目/关键词筛选，再创建服装FASH-2026-990001，款式可空 | 弹窗显示确切编号；成功只建立草稿。保留项目，清空已提交编号/款式，原列表条件不改 |
| 继续建下一件，或改选饰品创建JEW-2026-990001；两件款式可相同 | 可连续创建，物品编号唯一；项目改变后编号前缀需对应 |
| 点“查看该物品”或“完善该物品” | 按本次实际ID打开，不按最新第一行猜目标；返回来源保留筛选与页码 |
| 重复编号并改填款式，或填小写前缀/3位年份/5位序号/全角数字 | 明确拒绝并保留输入，不覆盖原记录、款式、时间或状态 |
| 查询编号、款式、资料名称、关联UID；展开关联及日期；分页、刷新、重置 | 完整服务端查询，显示匹配来源；日期为北京时间含首尾日，刷新及返回保留已提交条件，重置清条件回首页 |

空库、无匹配和读取失败的提示不同；读取失败不能显示0或伪空结果。默认每页20条，不要求cece为测分页灌入业务数据；不足一页边界禁用。创建未知结果先按本次完整编号核对，不自动重发；找到确切编号可查看，但不能仅据查询断定是谁创建。

## 3. 异常与技术检查

登录失效隐藏管理资料，重新登录后先核原结果。CSRF失效仅更新会话并保留输入，再由管理员明确提交；不会自动重放。创建、保存或上传回执不确定时，使用页面的核对动作，不能凭超时判断未保存。明确提示“图片上传未启用”表示本次已在接收文件前拒绝，不显示为未知结果；按第1节检查获准开发目标的上传配置，不因此开启生产上传。已确认成功与后续刷新失败分别提示；反馈页面、编号、操作和错误编号，不发密码、验证码、Cookie、真实.env或完整日志。

AI使用专属MySQL、合成图片和真实Chromium验证失败回滚、未知回执、取消晚到、并发及原尺码保留；不改现有业务库。复现命令集中在[本地运行](LOCAL_DEVELOPMENT.md#9-可重复的桌面浏览器回归)。自动通过不替cece宣布验收，测试资料可按明确批次清理，生产验证对象沿已确认单条删除规则处理。

## 4. 服装资料与启停验收

| 验收组 | 操作与预期 |
|---|---|
| 1. 详情、关联与编辑 | 打开服装详情，再进入编辑，对照全部适用字段名称/值；只有款式和服装资料可改，身份/状态/关联/配置/时间/尺码只读保留。关联芯片可打开真实详情，再返回原物品和列表 |
| 2. 普通保存与连续工作 | 同时改款式、名称及可选资料，一次“保存修改”；重读均保留且状态不自动改变。无修改不发送保存；可选清空生效，已有尺码不误清。仅改无资料物品的款式无需填名称，修改资料时名称必填 |
| 3. 图片全过程 | 选择合法静态图，等真实上传完成并预览；暂存不改变已保存图片，保存后详情可读。移除再保存才取消关联，文件按保留期维护。取消编辑或移除正在上传项不改变原关联，晚到回执不恢复已移除项；失败/未知有反馈，先明确重试/核对，不能显示假成功 |
| 4. 离开、失败与状态 | 修改后返回/导航/点关联，逐一检查取消、保存后继续、放弃继续；提交/上传中不离开。启用/停用另有确认，未保存先处理输入再确认状态，不隐式保存。启用需有效名称，停用保留资料与关联；不代表绑定/写卡/防伪完成 |
| 5. 只读及回归 | 饰品仅改款式，已有资料只读；归档全部只读。旧图片不再展示，需在共用款式重新上传；尺码表无编辑入口。登录、芯片登记/绑定/密钥与统计正常；1280×720及1440×900下可滚动到全部字段和操作 |

图片最多20项，文件/像素限制见[API第4.1节](../API_CONTRACT.md#41-私有图片上传暂存与读取)；排序、裁剪、饰品资料模板、归档/删除和纠错均不在本次范围。保存成功但原筛选不再匹配时，按提示调整查询，不重复创建补偿。用户侧资格/停用和真实公网另按[手机页手册](NFC_CARD_VERIFICATION.md#6-手机服装资料页与自动更新验收)，本页不声称已完成生产验证。
