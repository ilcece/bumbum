## 怎样避免手册越积越乱

- 新功能先补已有手册；只有形成独立操作流程时才新增文件，并把入口加到本索引。
- 目前使用现有 docs 目录即可，按主题分开维护手册，也不增加目录层级。以后确需分类搬迁，先同步链接，并保留旧入口，避免旧聊天链接失效。
- 手册说明怎么操作，规则仍以 PRD、TECH_SPEC、API_CONTRACT 和 schema 为准，不复制另一套字段或安全规则。
- 每次提交都按 [协作规范](../AGENTS.md#6-验证与交付) 核对代码、文档、分支范围和验证结果；格式检查不能代替人工核对内容。
