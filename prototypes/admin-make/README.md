## 页面组织

| 一级入口 | 用途 |
|---|---|
| 工作台 | 物品/芯片准备情况、有效触碰趋势及明细、当前账户与持有关系 |
| 款式与发行 | 共用款式资料独立维护页；固定/限时/不限量发行承诺及最终数量 |
| 数字物品 | 稳定身份、正式编号、独立售出确认、当前实体/芯片、持有人及历史 |
| 芯片管理 | 手工/演示Webhook登记、来源/批次、首次绑定、配置及服务状态 |
| 系统管理 | 必要操作审计、原型连接状态和未接入能力说明 |

订单、工厂、渠道上架和物流不再维护。款式/发行独立页面，物品/芯片独立详情；表格统一使用ProTable，编辑/只读使用ProForm/ProDescriptions。1280×720和1440×1000均按实际操作检查，详情及弹层随内容正常滚动。

## 建议验收的四组场景

### 1. 款式、发行与结果

工作台“新建款式”→保存→继续建立发行约定。手串50、T恤100和帽子共用流程；只有款式内容和发行约定不同。保存草案后再明确确认，确认不自动建物品或启用。已确认的数量规则/权益只读，当前或历史曾引用的禁止删除；共用资料修改提示影响引用物品。

限时发行不填预估上限，不提前生成100件。默认“棒球帽·限时发行”样例已到期，可直接核对外部最终137与依据并封版，不录137笔订单、不生成137个假物品。封版前已有稳定ID，正式编号待定；封版按稳定建档顺序编号，固定/不限量保护仍在。准备身份多于最终量会阻断核定，不自动删除身份凑数。

### 2. 建档、配卡与售出

从已确认发行“登记该发行物品”→首次绑定空闲芯片并录实际规格→到当前芯片准备演示密钥、核对两项配置步骤→返回同物品并启用。手工登记芯片也可从芯片入口开始，再选目标物品；重复UID拒绝覆盖。绑定/配置/启用均不自动认领或确认售出。

物品详情“维护售出确认”，或物品列表选择后批量确认。销售依据来自外部有效成交，只记录销售确认和首次时间；售出与认领分别存在。通过带标记的演示首次认领可继续验证换新/转售；真实短信、资格及所有权服务尚未接入。

### 3. 换新与转售延续

从已认领物品“办理换新/转售”：准备新绑定，选候选新芯片/新实体实际规格，核对资格和接收账户；候选配置就绪后，核对实际交付再明确“确认接续”。关闭可继续已保存准备。没有发货/运输步骤。

准备不切换授权或持有人；完成时旧卡退役、新关联生效，数字身份/发行编号/首次售出时间和历史保留。换新保持持有人；转售使用新实体/新芯片并更换持有人，不重置年度额度。换新计次显示“待核对计次”，不自行决定扣减、跨年、费用或争议政策。临时停用、挂失、退役分别处理；退役不可普通恢复。

### 4. 核心统计与异常恢复

工作台默认“售出后的有效触碰”，可切全生命周期及近7日/30日/累计，均显示北京时间。售出但未认领进入销售统计，赠品认领不自动成为售出。已认领物品/当前持有人是当前关系，不能用匿名触碰推算独立用户。

默认物品FASH-2026-000001：三代芯片售后10＋6＋4＝20次；生命周期另含5次售前试碰，共25次。配置核验、退役后尝试和重复读数不加次数。按稳定物品ID汇总，逐芯片展开，转售不把旧事件改记给现持有人。撤销售出确认保留时间、身份、归属和历史事件。

编辑中离开可继续编辑、放弃或保存后继续。顶栏模拟保存失败/未知，检查输入保留、核对后再明确重试；读取失败可重试，已有记录保留。列表查询条件、页码及详情返回来源可保留和刷新。
