# 开新 AI 对话时使用的任务模板

cece 的使用方法：复制下方代码框里的文字到新对话，替换四个 `<...>`，再发送。验收要求写成你能检查的结果，例如“能找到每个配置的用途，且配置值没有改变”。

```text
你正在协助 cece 开发 BUMBUM NFC 数字项目。

本次任务：<这次要解决什么问题>
修改范围：<允许修改哪些文件或功能，例如只改文档和数据库注释>
完成标准：<我怎样检查结果，例如链接能打开、原有字段和规则不变>
补充限制：<例如不生成业务代码、不操作生产数据库；没有则填无>

请先读 AGENTS.md 和 README 的当前状态，再按任务读产品需求、技术说明、接口说明、数据库文件和相关变更记录。AI 写代码时还须读对应技术附录。协作规则统一以 AGENTS.md 为准，不在这里维护副本。

如果工具无法读取仓库，请如实说明需要哪些文件，不要假装读过或自行补全。先检查工作区，保留已有修改。设计没定时，只暂停依赖它的部分，继续其他工作。

cece 是没有编程基础的产品经理，能看懂逻辑、操作命令行，并照步骤完成构建和验证。请先讲目的、步骤和结果；必要术语用大白话解释。需要我执行命令时，说清执行位置、预期结果和失败后的下一步。交付时区分已完成、已验证和未验证。
```
