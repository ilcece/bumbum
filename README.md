# BUMBUM NFC 数字项目

为服装、饰品等实体物品嵌入 NFC 芯片，让用户用手机碰一下，就能查看资料、验证真伪、绑定所有权，并在后续体验数字互动。

维护人 cece 是产品经理，没有编程基础，但能理解逻辑、操作命令行，并照步骤完成构建和验证。**项目文件以 cece 能读懂、判断、操作为标准：先讲目的、步骤和结果；必要术语用大白话解释。**具体要求见 [文件可读性原则](AGENTS.md#7-文件可读性以-cece-能理解为标准)。

## 现在做到哪一步

- 当前准备做第一阶段（Phase 1）：管理员登录、登记芯片、创建物品、维护绑定。具体完成标准见 [产品需求](PRD.md)。
- 管理员登录已选定简化方案：同一表单填写账号、密码、手机 Authenticator 验证码；首次设置和丢失后重置走服务器操作，保留登录会话及防冒用检查，不做备份码、不加 Redis。见 [登录流程](TECH_SPEC.md#4-管理员怎样登录)。
- 已完成第一小步：最小 Flask 后端、独立本地 MySQL、React 状态页面和启动检查。当前只检查程序与数据库，管理员登录及所有业务功能尚未实现，不代表第一阶段已完成。
- 建表文件写好了，不代表数据库已部署；方案选好了，也不代表真实芯片已通过测试。
- 已确认：全局 K1 先解开链接中的芯片编号，每枚芯片自己的 K2 再核对防伪码。其他密钥按项目、芯片编号和用途分别计算。初期只用 K1 的 v1，先解出编号再查所属项目，见 [密钥说明和流程图](TECH_SPEC.md#31-各把钥匙负责什么)。
- 全局 K1 泄露会影响该版本全部芯片的编号和读取序号隐私。具体权限、密钥计算规则和写卡参数仍需核对，并用一枚真实测试卡验证。养成由谁操作、怎样确认身份也还没定。当前不生成生产密钥或批量写卡。
- NFC.cool 能否按方案写卡、扫描后发来的数据长什么样、所选软件能否配合运行，仍缺少可复查的版本和测试记录。见 [尚未完成的检查](TECH_SPEC.md#9-还有什么没验证)。

1. 判断“要做什么、怎样才算做完”：读 [产品需求](PRD.md)。

cece 可以先读正文判断流程，按需查技术附录；AI 写代码时必须读对应的精确规则。需要执行命令时，说明必须包含执行位置、预期结果和失败后的处理方法。

## 选用的工具和业务分工

| 部分 | 使用什么 | 负责什么 |
|---|---|---|
| 用户页、管理页 | React + Vite + TypeScript | 浏览器中看到和操作的页面 |
| 后端 | Python 3 + Flask | 接收页面请求，检查身份，处理业务 |
| 数据库 | MySQL 8.0 | 保存芯片、物品、用户和操作记录 |
| 正式运行 | Gunicorn + Nginx | 分别运行后端、接收网站访问并转交请求 |
| 云服务 | 阿里云 ECS、RDS | 分别提供运行程序的服务器、托管数据库 |

一个仓库、一个后端、一个数据库。共同功能放在 `core/`；服装 `fashion` 和饰品 `jewelry` 的业务分开组织，避免同一功能写两遍。

计划两个网页应用（SPA，主要由浏览器切换页面），当前只建立管理端状态页：`nfc.bumbum.cc` 给用户，`admin.bumbum.cc` 给管理员。`bumbum.cc` 品牌页可选。芯片目标为 NXP NTAG424 DNA；真实写卡工具仍需按版本核验。

已有资源记录：阿里云 ECS（用户记录 Ubuntu 26.04，部署前核验实际版本）、RDS、备案中的 bumbum.cc、iPhone（iOS 14）、Windows 11 和 MacBook Air 2024。当前不增加微服务、Redis、消息队列等额外运行服务，避免维护负担。改变所用工具和部署方式前，须说明理由并获 cece 确认。

## 代码和配置在哪里

后端入口是 `app.py`，共同数据库连接在 `core/db.py`，当前前端在 `frontend/admin/`。`compose.yaml` 只启动独立测试数据库；首次给空库建表使用 `db/schema.sql`，已有库升级仍需另写迁移。

Python 的直接依赖在 `requirements.in`，完整固定版本在 `requirements.txt`；开发检查对应 `requirements-dev.in` 和 `requirements-dev.txt`。前端依赖与固定版本在 `package.json`、`package-lock.json`。更新依赖时同步对应清单，不手工改锁文件凑版本。

`.env.example` 是配置模板，准备脚本生成本机 `.env` 并保留已有文件。`VITE_` 配置会进入网页，只能放公开信息；接口地址拼接规则见 [接口说明](API_CONTRACT.md#01-地址和字段)。云开发环境与生产 ECS/RDS 分开，本轮没有连接生产数据库。
