仅用于独立模拟验收批次，不代表自有商品、品牌合作、真实材质鉴定、真实交易或实际交付。六张实物照片均已人工查看；绘画、模糊图及重复候选未采用。下载来源、作者、原图页面、原始许可与重编码说明保存在[catalog.json](catalog.json)每项photo中。CC BY / CC BY-SA图片保留原许可与署名；同许可要求适用于对应WebP衍生照片，项目其他代码不因照片许可而改变。

图片通过项目现有静态图片解码/去元数据/重编码函数处理，无运行时外链请求，离线工具校验SHA256后入style_image，并随SQL备份。公开来源仅用于追溯许可，实际后台/H5图片仍受原认证和查看资格约束，不增加公开图片入口。日期：2026-11-06。
